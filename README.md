# 사물함 보드 임시 제어 프로그램 사용 설명서

## 0. 이 프로그램은 뭐 하는 거예요?
컴퓨터와 사물함 보드를 **RS485 선**으로 연결해서, 버튼을 누르면 사물함 문이 열리게 하는 프로그램입니다.
화면 아래쪽에 컴퓨터가 보낸 신호(TX, 파랑)와 보드가 돌려준 신호(RX, 초록)가 그대로 보입니다.

## 1. 준비물
| 준비물 | 설명 |
|---|---|
| 윈도우 컴퓨터 | |
| USB-RS485 변환기 | 컴퓨터 USB ↔ 보드 A/B 선 연결용 (드라이버 설치 필요할 수 있음) |
| 사물함 보드 | 전원 DC 12~24V 연결 |
| Python 3.10 이상 | https://www.python.org/downloads/ 에서 설치 |

> ⚠️ Python 설치 첫 화면에서 맨 아래 **"Add python.exe to PATH"** 에 꼭 체크하세요!

## 2. 프로그램 설치 (딱 한 번만)
1. 키보드 `윈도우키` 누르고 `cmd` 입력 → 엔터 (검은 창이 열림)
2. 아래 한 줄을 붙여넣고 엔터
```
pip install pyserial pyinstaller
```
(`tkinter`는 Python에 들어 있어서 따로 설치하지 않아도 됩니다.)

## 3. 그냥 실행해 보기 (빌드 없이)
1. `locker_control.py`가 있는 폴더를 연다
2. 주소창에 `cmd` 입력 후 엔터 (그 폴더에서 검은 창이 열림)
3. 아래 입력
```
python locker_control.py
```

## 4. exe 파일로 만들기 (빌드)
같은 검은 창에서:
```
pyinstaller --onefile --windowed locker_control.py
```
- 1~2분 기다리면 `dist` 폴더 안에 **`locker_control.exe`** 가 생깁니다.
- 이 exe 파일만 다른 컴퓨터에 복사해도 실행됩니다 (Python 설치 필요 없음).

## 5. 사용 방법
1. 보드 전원을 켜고, USB-RS485 변환기를 컴퓨터에 꽂고 보드 A/B 선에 연결
2. 프로그램 실행 → **포트**(예: COM3) 선택
   - 모르겠으면: `윈도우키 + X` → 장치 관리자 → "포트(COM & LPT)" 에서 확인
3. 속도는 기본 **9600** 그대로 → **연결** 버튼
4. **보드 번호**(보드의 DIP 스위치로 정한 번호)와 **칸 번호**를 입력
5. 버튼 사용
   - **이 칸 열기**: 입력한 칸 하나 열기
   - **전체 열기**: 보드의 모든 칸을 열기 (0.3초 간격으로 차례로 열림)
   - **이 칸 / 전체 상태조회**: 문이 열렸는지 닫혔는지 확인
   - **여러 칸 열기**: `2,10,18` 처럼 적으면 한 번에 열기
   - 3번 영역의 **숫자 버튼 1~50**: 위에 입력한 보드 번호로 해당 칸 열기
   - **직접 보내기**: `8A 01 01 11` 처럼 적으면 체크코드를 자동으로 붙여 전송
6. 맨 아래 로그에서 TX/RX 확인

## 6. 안 될 때
| 증상 | 확인할 것 |
|---|---|
| 포트가 안 보임 | 변환기 드라이버 설치, USB 다시 꽂고 **새로고침** |
| "포트를 열 수 없습니다" | 다른 프로그램이 같은 포트를 쓰는 중인지 확인 |
| TX만 나오고 RX가 없음 | A/B 선이 바뀌었는지, 보드 번호가 맞는지, 속도가 9600인지, 전원 확인 |
| 문이 안 열림 | 보드 번호/칸 번호 확인, 잠금장치 전원(12~24V) 확인 |

## 7. 알아두면 좋은 점
- 응답 해석(열림 성공/실패, 열림/닫힘)은 **"닫힘 감지형" 전기락 기준**입니다. 문 열림 감지형이면 0과 1의 뜻이 반대이니, 로그의 16진수 값(`00`/`11`)을 기준으로 보세요.
- 체크코드(BCC)는 앞의 모든 바이트를 XOR 한 값이며, 프로그램이 자동으로 계산합니다.
- 칸 버튼은 1~50개(50칸 보드 기준)가 있고, 한 칸 열기/상태조회는 칸 번호를 그대로 보드에 보냅니다. 단, 전체 상태조회와 여러 칸 열기는 문서상 보드 1장당 1~24칸까지라 25칸 이후는 지원하지 않습니다. 보드 번호는 DIP 스위치로 정한 값을 입력하세요.
- 사진의 "customized 기능"(자동 보고, 장시간 통전, 속도 변경)은 기본 제공이 아니라서 넣지 않았습니다.
